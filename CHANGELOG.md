# Changelog

User-visible changes to Submarius. Each entry corresponds to an App Store
release of the iOS app and a deploy of the web app.

This changelog is the public reflection of our internal release notes;
internal hotfixes and infrastructure-only changes are omitted unless they
affected user-visible behaviour.

The format is loosely inspired by [Keep a Changelog](https://keepachangelog.com/),
but versions correspond to App Store build numbers rather than semver.

---

Documentation repository launched. No app changes.
