# Contributing

Thanks for taking an interest. A few things to know up front, because this
repo is structured differently from a typical open-source project.

## What this repo is

This repository contains **public documentation only** — methodology, FAQ,
glossary, changelog, press kit. The Submarius source code (Go backend, React
apps, admin tools) is not open source and is not hosted here.

## What we accept

- **Bug reports about the app** — file an issue using the
  [bug template](.github/ISSUE_TEMPLATE/bug.yml). Bugs filed here are
  triaged into our internal tracker; you'll get a response when there's
  something to share.
- **Methodology questions and discussion** — file an issue using the
  [methodology question template](.github/ISSUE_TEMPLATE/methodology-question.yml),
  or open a thread under [Discussions](../../discussions). Public Q&A on the
  models is genuinely useful — we'd rather answer once in the open than ten
  times by email.
- **Documentation fixes** — typos, broken links, factual errors in
  the public docs. Open a pull request; we read every one.
- **Citation suggestions** — if you know of a paper that strengthens or
  contradicts the methodology described here, please open an issue. The
  model is grounded in published oceanography and we want the citations
  to be right.

## What we don't accept

- **Source code contributions.** The product is closed-source. PRs that
  add or modify code outside the documentation will be closed without
  review.
- **Feature requests filed as issues.** The roadmap is curated based on
  user research and what users actually do in the app. Open a discussion
  thread instead — we read those, but we don't track issues for things
  we may or may not build.
- **"Add my spot" or "add my region" requests.** Submarius covers any
  coastal location worldwide automatically; there's no allow-list to
  add to.

## Reporting security issues

Please do not file public issues for security vulnerabilities. See
[SECURITY.md](SECURITY.md) for the disclosure process.

## Code of conduct

By participating in this repo's issue tracker, discussions, or pull
requests, you agree to abide by the [Code of Conduct](CODE_OF_CONDUCT.md).
